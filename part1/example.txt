\section{Filter Selection and Optical Justification}

We chose a \textbf{2D Gaussian kernel} to model the blur observed in the background of the reference photograph. Our choice is based on the following observations:

\begin{enumerate}
\item \textbf{Smooth blurring:} The background in the reference image appears smoothly blurred, with fine details and sharp edges gradually fading rather than disappearing abruptly. Gaussian filtering produces exactly this kind of smooth transition.


\item \textbf{Greater influence of nearby pixels:} A Gaussian kernel assigns the highest weight to the center and progressively smaller weights to pixels farther away. Thus, when calculating an output pixel, nearby pixels have a greater influence than distant pixels. This produces a natural and gradual blur.

\item \textbf{Reduction of fine details:} Gaussian filtering is a smoothing and low-pass filtering operation. It reduces high-frequency details such as sharp edges and small textures while retaining the overall brightness and larger structures of the image. This is consistent with the appearance of an out-of-focus background.

\item \textbf{Creating visual separation:} Blurring the background reduces its visual detail and sharpness, making the main object in the photograph stand out more clearly. This is similar to the effect of shallow depth of field in photography, where the subject appears sharp while the background fades into a soft blur.

\end{enumerate}

The Gaussian kernel is given by:

\begin{equation}
K(x,y) = \frac{1}{Z}\exp\left(-\frac{x^2+y^2}{2\sigma^2}\right)
\end{equation}

where $\sigma$ controls the spread of the blur and $Z$ normalizes the kernel so that all its values add up to 1.
\vspace{-0.5 cm}

We chose the Gaussian kernel because its weights decrease smoothly as we move away from the center. Thus, nearby pixels have a greater influence on the output pixel than pixels farther away, producing a natural-looking blur.

\section{Parameter Variation Comparison}

We experimented with different kernel sizes and values of $\sigma$ to see how they affect the amount of blur. The same three configurations were applied to two images:

\begin{itemize}
\item \textbf{Low Blur:} $15 \times 15$, $\sigma=3$
\item \textbf{Medium Blur:} $31 \times 31$, $\sigma=7$
\item \textbf{High Blur:} $61 \times 61$, $\sigma=15$

As the kernel size and $\sigma$ increase, pixels from a larger neighborhood contribute to each output pixel, resulting in a stronger and smoother blur.

\section{Gamma Transformation Comparison (With vs. Without Gamma)}

Before convolution, we apply a gamma transformation with $\gamma=2.2$ and perform the convolution in the transformed space. The gamma is then undone using $\gamma=1/2.2$.

The three steps are:

\begin{enumerate}
\item \textbf{Gamma transformation:}
[
I\_{\text{linear}} = I\^{2.2}
]


\item \textbf{Convolution:}
\[
I_{\text{blurred}} = I_{\text{linear}} * K
\]

\item \textbf{Inverse gamma transformation:}
\[
I_{\text{final}} = I_{\text{blurred}}^{1/2.2}
\]


\end{enumerate}

The reason for using this procedure is that convolution involves averaging pixel intensities. Since image intensities are stored in a gamma-encoded form, directly averaging these values does not correspond exactly to averaging physical light intensities. Converting to approximately linear-light values before convolution therefore gives a more physically meaningful result.

\subsection{Observations}

\begin{enumerate}
\item \textbf{Image 1:} The difference between the two blurred outputs is most noticeable around the brighter lights and colored objects. The gamma-corrected result retains brighter and more natural-looking highlights.


\item \textbf{Image 2:} Both methods produce a similar amount of blur, but the gamma-corrected result gives slightly different brightness and contrast in the blurred regions. This shows that gamma correction affects the intensity of the blur rather than the spatial extent of the kernel.

\item \textbf{Image 3:} The fine text details are strongly blurred in both cases. Gamma correction does not recover details that have been removed by the low-pass filter; it mainly affects the resulting intensity values.

\item Overall, the gamma-corrected results are more physically meaningful because the convolution is performed on approximately linear-light intensities rather than directly on gamma-encoded pixel values.


\end{enumerate}
\section{Algorithm Pseudocode}
\begin{lstlisting}[
    language=Python,
    caption={Pseudo-code},
    label={lst:gaussian_gamma}
]
INPUT: RGB image I
PARAMETERS: kernel_size = 21, sigma = 5, gamma = 2.2

Normalize I to [0, 1]

Create and normalize Gaussian kernel K

Pad I using edge replication

FOR each pixel (i, j):
    FOR each RGB channel c:
        normal_blur[i,j,c] = sum(region * K)

Apply gamma transformation:
    gamma_image = I ^ gamma

Pad gamma_image using edge replication

FOR each pixel (i, j):
    FOR each RGB channel c:
        gamma_blur[i,j,c] = sum(region * K)

Apply inverse gamma transformation:
    final_image = gamma_blur ^ (1 / gamma)

Clip both outputs to [0, 1]
Convert outputs to 8-bit images
Save normal_blur as output_3a.png
Save final_image as output_3b.png
\end{lstlisting}
